## Purpose

This document explains the visualizations created for the credit card fraud analytics project.

The goal is to use charts to make transaction behavior, fraud distribution, and business patterns easier to understand.

## Visualization List

| Chart | File | Purpose |
|---|---|---|
| Fraud Distribution | `images/charts/class_distribution.png` | Shows the split between fraud and non-fraud transactions |
| Transaction Amount Distribution | `images/charts/transaction_amount_distribution.png` | Reviews how transaction amounts are distributed |
| Transactions by Hour | `images/charts/transactions_by_hour.png` | Shows transaction activity across hours |
| Fraud by Transaction Location | `images/charts/fraud_by_transaction_location.png` | Compares fraud activity by location |
| Device Trust Score Distribution | `images/charts/device_trust_score_distribution.png` | Shows device trust score behavior |
| EDA Summary | `images/charts/eda_summary.png` | Provides a combined visual summary of analysis outputs |

## Visualization Principles

- Use simple charts that are easy to explain.
- Keep chart titles clear and business-focused.
- Avoid overly complex visuals.
- Focus on comparison, distribution, and trend understanding.
- Use visuals to support insights, not replace explanation.

## Business Use

These charts help stakeholders quickly understand:

- How common fraud is in the dataset
- Whether transaction behavior changes by hour
- Which locations need closer review
- How transaction amount behaves across records
- Whether device trust score provides useful risk context

## Why This Matters

Visualizations make analysis easier to understand for non-technical stakeholders.

For a Data Analyst portfolio, clear charts show communication skills, business thinking, and the ability to turn data into an understandable story.
