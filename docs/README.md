## Purpose

This folder contains supporting documentation for the credit card fraud analytics project.

The documents explain the business problem, data cleaning approach, exploratory analysis, business metrics, insights, and visualization choices.

## Documentation Files

| File | Purpose |
|---|---|
| `business_problem.md` | Explains the project context, problem statement, objectives, and business questions |
| `data_cleaning.md` | Documents the data cleaning approach and quality checks |
| `exploratory_data_analysis.md` | Explains the EDA process and analysis focus areas |
| `business_metrics.md` | Defines fraud-related business metrics used in the project |
| `business_insights.md` | Summarizes key findings and operational recommendations |
| `visualizations.md` | Explains the charts created and their business purpose |

## Why This Matters

Strong documentation makes the project easier for recruiters, hiring managers, and interviewers to understand.

It also shows that the project is not only code-focused, but includes business thinking, communication, and structured analysis.
