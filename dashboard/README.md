## Purpose

This folder contains the Streamlit dashboard for presenting fraud-related KPIs and visual summaries.

The dashboard is designed for business reporting and operational monitoring. It is not intended for machine learning or predictive modeling.

## Dashboard Focus Areas

- Total transactions
- Fraud transactions
- Fraud rate
- Transaction amount analysis
- Fraud by transaction location
- Fraud by transaction hour
- Device trust score trends
