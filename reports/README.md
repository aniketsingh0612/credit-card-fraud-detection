## Purpose

This folder contains business-facing reports created from the credit card fraud analytics project.

The reports summarize analysis findings, business observations, and practical recommendations for fraud monitoring teams.

## Report Files

| File | Purpose |
|---|---|
| `fraud_analysis_summary.md` | Summarizes key findings, business recommendations, and suggested reporting metrics |

## Why This Matters

Reports show that the analysis can be communicated beyond code and charts.

For a Data Analyst portfolio, this demonstrates business communication, stakeholder awareness, and the ability to convert analysis into useful recommendations.
